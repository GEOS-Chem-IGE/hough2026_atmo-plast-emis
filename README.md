Code and data for 'Reduced global atmospheric microplastic emissions from size-harmonized observations' (Hough et al., 2026)
============================================================================================================================

[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.22924039.svg)](https://doi.org/10.5281/zenodo.22924039)

This record provides a single entry point to the data and code for the paper "Reduced global atmospheric microplastic emissions from size-harmonized observations" (Hough et al., 2026). It is archived at https://doi.org/10.5281/zenodo.22924039.

The code resources can also be obtained by cloning the corresponding [git repository](https://github.com/GEOS-Chem-IGE/hough2026_atmo-plast-emis) and its submodules:

```bash
git clone --branch v1.0.0 --depth 1 --recurse-submodules --shallow-submodules https://github.com/GEOS-Chem-IGE/hough2026_atmo-plast-emis.git
```
