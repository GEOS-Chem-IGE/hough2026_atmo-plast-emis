Reduced global atmospheric microplastic emissions from size-harmonized observations (Hough et al., 2026)
========================================================================================================

[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.22924039.svg)](https://doi.org/10.5281/zenodo.22924039)

This repository provides a single entry point to the data and code for the paper "Reduced global atmospheric microplastic emissions from size-harmonized observations" (Hough et al., 2026). The underlying resources are maintained as separate records to preserve their respective authorship, metadata, and versioning.

The resources are:

1. **Code** to simulate global atmospheric microplastic emissions, transport, and removal with GEOS-Chem: [![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.22864952.svg)](https://doi.org/10.5281/zenodo.22864952)

2. **Dataset** of raw simulation outputs: [![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.20847720.svg)](https://doi.org/10.5281/zenodo.20847720)

3. **Code** to size-harmonize atmospheric microplastic observations collected from the literature and constrain the simulation outputs to match the size-harmonized observations: [![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.21069346.svg)](https://doi.org/10.5281/zenodo.21069346)

4. **Dataset** of size-harmonized observations and constrained simulation outputs: [![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.22865719.svg)](https://doi.org/10.5281/zenodo.22865719)

5. **Code** to plot the paper figures: [![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.21070175.svg)](https://doi.org/10.5281/zenodo.21070175)


The code resources can also be obtained by cloning this repository and its submodules:

```bash
git clone --depth 1 --recurse-submodules --shallow-submodules https://github.com/GEOS-Chem-IGE/hough2026_atmo-plast-emis.git
```
